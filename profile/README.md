FDRTools Advanced is a stacking helper for bracketed photos from home, class, or a small personal project. FDRTools Advanced exposure stack is the input: several exposures, same place, same moment as far as the camera allowed. FDRTools Advanced hdr merge turns that stack into one range. FDRTools Advanced ghost mask sits between them, because a walker or a waving branch should not be averaged into a blur. Choose the compressor first if the goal is a believable print.
